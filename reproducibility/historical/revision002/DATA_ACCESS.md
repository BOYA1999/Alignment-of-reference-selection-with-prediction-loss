# Data access and distribution scope

Public sources remain version-pinned: ExpansionRx revision 6b898ccc43d10d25b230fb09e22a6e30c30022b5, DOI 10.57967/hf/9687 (development only); Biogen official ADME revision b00df003de117ce9e5b381afd886095c5f2af2d5, article DOI 10.1021/acs.jcim.3c00160 (sole original confirmation); PXR revision 8041adfc295cac7f0bf85b73a2d87f21c5302ab1, DOI 10.57967/hf/9731 (separate record/selection audit). Source manifests and fetch_public_inputs.py give URLs, hashes and recorded licenses. The Biogen derivative is pinned to PatWalters/expansion-ml-comparison revision 06582771d48af8096f6b05a5a247b177189a8fa4. RUNBOOK.md separates derivative retrieval from independent split reconstruction.

This package includes original aggregate results, post-result setting-level estimates, summaries and protocols, non-molecular alignment simulation records, current figure/table source data, numerical solver comparisons and a minimal case trace. Revision 002 intentionally adds the public-source locator Mol2946 / zero-based source row 2945 and limited numerical contribution fields so the specific mechanism can be checked. Counts and estimate rows are repeated settings, not independent compounds or cohorts. Earlier redactions remain documented in verification/distribution_redactions.json; those earlier redaction records do not describe the new permitted case locator.

Excluded: raw assay copies, SMILES/canonical structures/scaffolds, full compound-level prediction/fold/generator vectors, PXR linkage records, local feature caches, 1,600 row-vector NPZs, user review attachments, local environments, previous ZIPs and author Word files. References or hashes for excluded files are reconstruction requirements, not claims of inclusion. The case entry retrieves the pinned official source in memory; it does not create an unofficial molecular-data mirror.

Software licensing does not authorize third-party data redistribution. Authors must verify source terms, approve an aggregate-data license, complete creator/affiliation/ORCID/funding metadata, and create/test a permanent repository and reviewer-access record. No new repository DOI or public/private reviewer link has been assigned by this workflow.
